# SpendWise

A Flutter app to track daily expenses, view balance and manage budget.

## Features
- Add Expense with Category
- View Total Spent and Balance
- Filter by Category
- Delete Expense
- Budget Overview



## How to Run
1. Open in DartPad (dartpad.dev) - Select Flutter
2. Paste lib/main.dart code
3. Click Run
